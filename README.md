# GameQuest-Trio
 
Description
GameQuest Trio is a collection of three engaging and easy-to-play Python games designed to entertain and challenge players. This project includes:

Hide Card Number: A fun card guessing game where players try to guess the hidden card number from a set of cards.

MyMysteryNum: A number guessing game where players attempt to guess a mystery number generated by the computer within limited attempts.

Rock Paper Scissors: The classic hand game played against the computer to test your luck and strategy.

These games are developed using Python and are perfect for beginners looking to practice programming concepts such as input/output handling, conditional logic, loops, and randomization.

Installation
To run these games, you need to have Python installed on your computer. You can download Python from python.org.

Clone this repository or download the source code as a ZIP file.

Navigate to the project directory in your terminal or command prompt.

Run any of the game scripts using the Python interpreter:

python hide_card_number.py
python mymysterynum.py
python rock_paper_scissors.py
How to Play
Hide Card Number
The game will shuffle a set of cards with numbers.

One card is hidden, and you have to guess the number on the hidden card.

Try to guess correctly to win the game.

MyMysteryNum
The computer will generate a random number within a specified range.

You will be given multiple attempts to guess the mystery number.

After each guess, you will receive hints whether your guess was too high or too low.

Guess the number correctly before running out of attempts to win.

Rock Paper Scissors
Choose one of the three options: Rock, Paper, or Scissors.

The computer will randomly choose its option.

Rock beats Scissors, Scissors beats Paper, Paper beats Rock.

The winner is decided based on these rules.

Features
Simple command-line interface for easy interaction.

Clear prompts and feedback messages to guide players.

Randomized game elements to ensure a different experience every time.

Suitable for all age groups and especially useful for Python beginners.

No external dependencies required; runs on standard Python installation.
